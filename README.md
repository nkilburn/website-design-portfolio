# website-design-portfolio

A premium portfolio website for NorthNinth — a web design and AI automation agency.

## Live deployment

This site is built with Vite and deployed as a static project. If GitHub Pages is used, the published site should be available at:

https://nkilburn.github.io/website-design-portfolio

> Note: the live URL currently returns 404, so the repository may need Pages to be enabled in GitHub settings or the branch configured for deployment.

## Local development

1. Install dependencies

   npm install

2. Start the dev server

   npm run dev

3. Build for production

   npm run build

4. Preview the build

   npm run preview

## Project structure

- `index.html` — main site page
- `src/styles.css` — project styling
- `src/main.js` — UI interactions and hero tab state
- `vite.config.js` — Vite configuration
- `package.json` — scripts and dependencies
- `.gitignore` — excluded files
